# PHP Básico

Atividades práticas de Programação Web I (Técnico em Informática).

**Aluno:** Mayume Souza

## Projetos

- 01-hello-world: primeira página em PHP
- 02-data-hora: data e hora do servidor
- 03-imc: calculadora de IMC
- 04-produtos: lista de produtos com array associativo

## Como executar

1. Instalar o Laragon e iniciar os serviços.
2. Colocar esta pasta em `C:\laragon\www\php-basico`.
3. Abrir `http://localhost/mayume/php-basico/` no navegador.

## O que aprendi

- Aprendi a criar páginas usando PHP e HTML.
- Aprendi a criar e utilizar variáveis em PHP.
- Aprendi a trabalhar com condições `if`, `elseif` e `else`.
- Aprendi a usar arrays e `foreach` para organizar e exibir dados.
- Aprendi a criar funções e formatar valores.
